# Knowledge-graph legend for the paper PNGs

These figures are snapshots of the project knowledge graph, so the legends must match the graph's actual visual vocabulary.

## Graph styling used in the project

### Node colors

- PERSON: blue (#4c72b0)
- GROUP: purple (#8172b2)
- LOCATION: green (#55a868)
- COMMODITY: red (#c44e52)
- CONCEPT: brown (#937860)
- RESEARCH FOCUS: yellow (#ffcc00)

### Edge colors by relation

- trades_with: green (#2f8f5b)
- extracts_from: orange-brown (#b86b2b)
- taxes: red (#c73e3a)
- licenses: purple (#7d5cc6)
- controls: dark brown (#8a4a24)
- governs: blue (#315f9f)
- supplies: gold (#c28f00)
- depends_on: gray (#6f7c85)
- transports_via: teal-blue (#2f80c0)
- monopolizes: maroon (#7f3b3b)
- disputes: crimson (#d62728)
- negotiates_with: tan (#8b6f3d)

### Circuit border colors

- Salt anchor: yellow (#ffcc00)
- Commodity circuits: red (#c44e52)
- Political economy: blue (#315f9f)
- Route/place circuits: green (#55a868)
- Social actors: purple (#8172b2)
- Conceptual context: brown (#937860)

### Shape convention

All graph nodes are represented as dots in the generated network, with the node color and circuit border together indicating type and circuit membership.

This is the style the figure legends must mirror. The legend panel added to each PNG follows these exact project conventions rather than a generic map-style legend.
